## 使用方式

在 X/Twitter 发推时，把对应链接贴在推文末尾，系统会自动抓取 `summary_large_image` 大卡片预览。

如果首次发布没有显示大卡片，请到 https://cards-dev.twitter.com/validator 粘贴链接刷新缓存。
